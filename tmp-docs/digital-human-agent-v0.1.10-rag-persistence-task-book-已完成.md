# 数字人 Agent v0.1.10 RAG 持久化任务书

## 目标

将 RAG 向量索引从进程内存迁移为可持久化的 SQLite 存储，确保文档入库后服务重启仍可检索，同时保持现有 VectorStore 接口和权限隔离。

## 范围

- 新增 SQLite VectorStore 适配器，保留内存实现用于单元测试。
- 增加 `RAG_STORE_PATH` 配置和 Docker 数据卷。
- RAG 状态页标识真实存储后端。
- 增加写入、检索、删除、重启恢复测试。

## 验收标准

- [x] 文档入库后可从新建的服务实例继续检索。
- [x] 不同用户和集合之间的数据保持隔离。
- [x] 删除文档后重启不会恢复已删除内容。
- [x] 超过容量时按最旧记录淘汰，服务不崩溃。
- [x] Agent 全量测试、Web 构建和 Docker 健康检查通过。
