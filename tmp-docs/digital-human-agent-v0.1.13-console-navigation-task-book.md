# 数字人 Agent v0.1.13 导航布局收敛任务书

## 原始问题

桌面控制台左侧导航占用宽度偏大，中等屏幕断点仍然使用较宽轨道；页面滚动时需要确保仅主内容区滚动，导航保持独立且不被内容滚动带动。根字体与导航品牌区的尺寸也需要保持同一套紧凑比例。

## 实施范围

- 收窄桌面与中等屏幕导航轨道和品牌区最小宽度。
- 保持折叠导航、移动端抽屉导航和主内容区滚动行为不变。
- 增加静态样式回归检查，避免后续改动重新引入宽导航或页面整体滚动。

## 验收标准

1. 桌面导航轨道为 208px，折叠轨道保持 72px。
2. 中等屏幕导航轨道不超过 192px，品牌区最小宽度与轨道匹配。
3. `.console-shell` 保持视口高度并隐藏外层溢出；`.console-main` 继续承担垂直滚动，导航不随主内容滚动。
4. Web TypeScript 构建通过，新增回归检查通过。
5. 功能变更版本号统一提升至 `0.1.13` 并提交。

## 回滚边界

仅回滚本任务涉及的导航尺寸、溢出约束、回归检查和版本号变更，不触碰数字人 Provider、RAG、鉴权等业务逻辑。
