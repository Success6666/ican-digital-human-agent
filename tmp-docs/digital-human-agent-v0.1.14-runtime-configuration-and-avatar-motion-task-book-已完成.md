# 数字人 Agent v0.1.14 运行配置与数字人动效任务书

状态：已完成（2026-08-31）

## 原始问题

1. 首页数字人连接后主要表现为静态预览，星云 SDK 的动作/播报链路没有形成可验证的动态闭环。
2. 后台配置页面只能修改部分数字人 Provider，LLM、Embedding、Docling 和 FutureAGI 配置没有真实的后端字段、持久化和运行时应用能力。
3. 管理员在前端无法完成上述配置的读取、修改和保存，配置页面与后端实际能力不一致。

## 实施范围

- 将 LLM、Embedding、Docling、FutureAGI 配置加入服务端配置模型、校验、原子持久化和运行时应用。
- 将前端配置拆分为小型弹窗卡片，提供真实可编辑字段、敏感字段掩码和保存反馈。
- 修复星云浏览器 SDK 的文本播报与动态状态同步，确保收到 Agent 回复后调用 SDK 的动态播报接口；失败时展示可诊断状态而不是静默退回静图。
- 保留 Provider 凭证的服务端托管原则，不向前端返回完整密钥。

## 验收标准

1. `GET /api/configuration`（管理员）返回 LLM、Embedding、RAG/Docling、FutureAGI 的当前实际配置状态。
2. `PATCH /api/configuration`（管理员）可分别保存上述配置，重启 Agent 服务后配置仍存在并生效；普通用户无法读取或修改。
3. LLM、Embedding、Docling、FutureAGI 弹窗字段可编辑，保存成功后重新读取显示一致，错误由后端返回并在人类可读位置展示。
4. 首页收到 Agent 回复时，星云 Runtime 调用动态播报接口；状态至少可区分连接、播报、停止和失败，不再把静态预览当作已连接动态 Runtime。
5. Agent 单元测试、Web 构建与相关前端测试全部通过；Docker 服务健康。
6. 版本统一提升至 `0.1.14`，完成任务书改名为带 `-已完成` 后缀并提交。

## 回滚边界

仅回滚本任务新增的配置域、运行时应用、前端弹窗及星云动态播报适配，不回滚既有鉴权、RAG SQLite、导航布局和会话中断能力。
