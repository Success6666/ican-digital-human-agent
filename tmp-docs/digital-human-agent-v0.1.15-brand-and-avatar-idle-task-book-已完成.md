# Digital Human v0.1.15 品牌与数字人常驻展示任务书

状态：已完成（2026-08-31）

## 原始问题

1. 没有建立真实会话时，首页无法稳定显示已保存的数字人预览。
2. 顶部品牌使用“ICAN 数字人”，侧栏又显示“Digital Human”，品牌标识重复且冲突。
3. 顶部右侧和左侧导航底部重复显示账号信息，页面信息密度不合理。

## 实施范围

- 无真实会话时优先展示已保存的数字人及背景预览。
- 仅在对话、录音或用户主动建立会话时连接星云 Runtime。
- 统一品牌文字为 `Digital Human`，移除侧栏重复品牌文字。
- 保留左侧导航底部账号信息，移除顶部右侧账号信息。

## 验收标准

1. 首页未建立会话时，若存在已保存预览，中央仍显示数字人和背景，而不是空白等待态。
2. 首页开始对话或录音时才创建/使用星云 Runtime；停止交互后可回到预览。
3. 所有页面顶部品牌均显示 `Digital Human`，侧栏不再出现第二处品牌文字。
4. 每个页面左侧导航底部显示当前账号，顶部右侧不再显示账号头像和名称。
5. Web 构建、布局测试通过，版本提升至 `0.1.15`，任务书改名为带 `-已完成` 后缀。
