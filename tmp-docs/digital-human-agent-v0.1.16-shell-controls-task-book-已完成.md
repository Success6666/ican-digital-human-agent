# Digital Human v0.1.16 壳层控制与退出入口任务书

状态：已完成（2026-08-31）

## 原始问题

1. 侧栏顶部仍有重复品牌图标，占用工作区空间。
2. 导航收起按钮位置不自然，和重复品牌元素绑定。
3. 顶部存在退出登录图标，和左下角账号操作入口重复。

## 实施范围

- 删除侧栏顶部重复品牌图标区域。
- 将导航收起按钮移动到“工作区/导航”标题行。
- 移除顶部退出登录图标，仅保留左下角账号区域的三个点作为退出入口。
- 收起导航后仍保留三个点入口。

## 验收标准

1. 侧栏顶部不再显示重复品牌图标。
2. 收起/展开按钮位于侧栏标题行，桌面端和移动端均可操作。
3. 顶部右侧不显示退出登录图标；左下角账号区域显示三个点并可退出登录。
4. Web 构建、布局测试通过，版本提升至 `0.1.16`，任务书改名为带 `-已完成` 后缀。
