# Digital Human v0.1.17 未连接待机动效任务书

状态：已完成（2026-08-31）

## 原始问题

未建立星云真实会话时，首页保存的数字人预览是静态图片，视觉上像页面没有响应。

## 实施范围

- 在本地静态预览层增加低幅度、低性能成本的待机呼吸与浮动动效。
- 不改变“对话或录音时才建立星云真实连接”的会话策略。
- 对系统减少动态效果偏好提供无动画降级。

## 验收标准

1. 未连接且存在预览时，数字人持续有平滑的待机位移动效。
2. 动效不改变数字人水平居中、底部对齐和背景比例。
3. 真实 Runtime 连接时不叠加本地预览动效。
4. `prefers-reduced-motion: reduce` 下关闭待机动效。
5. Web 构建与布局测试通过，版本提升至 `0.1.17`，任务书改名为带 `-已完成` 后缀。
