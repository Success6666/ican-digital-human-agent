# Digital Human v0.1.18 导航栏与中文 Embedding 任务书

## 原始问题

顶部栏重复显示当前页面标识，导航栏顶部存在多余的“工作区”区域；导航栏收起按钮位置不自然；左下角运行服务状态与顶部状态重复。现有 Embedding 只有特征哈希和远端兼容模式，缺少中文开源模型本地部署能力。

## 实施范围

1. 删除顶部重复的页面图标与页面名称，保留侧边导航高亮作为唯一页面定位。
2. 删除导航栏顶部“工作区”区块，将收起/展开按钮移入导航区域。
3. 删除左下角运行服务状态行，顶部保留全局运行状态。
4. 增加 SentenceTransformers 本地 Embedding 适配器，默认模型为 BAAI/bge-small-zh-v1.5，支持本地目录或模型仓库标识。
5. 保留 OpenAI 兼容远端 Embedding 和哈希兜底模式，并在后台配置弹窗中提供部署方式选择。

## 验收标准

- 所有页面顶部不再出现重复的页面图标和页面名称。
- 导航栏仍可正常高亮、切换、收起和展开；移动端关闭按钮可用。
- 左下角仅保留账号信息与退出入口，运行状态只在顶部显示。
- 后台配置可选择本地中文模型、远端兼容服务或哈希兜底，配置保存后由 RAG 服务读取。
- 本地模式缺少依赖或模型时返回明确错误，不静默伪装为真实向量。
- Web 构建、布局测试、实时链路测试和 Python 编译检查通过；版本号提升至 0.1.18。
