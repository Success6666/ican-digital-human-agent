# 数字人 Agent v0.1.20 语音与首页实时体验任务书

## 1. 原始问题

首页输入框占据独立底部区域，数字人场景没有铺满；导航收起按钮位于导航内容中且图标不符合参考风格。语音按钮因后端 ASR/TTS 未配置而不可点击，用户无法完成语音输入。

## 2. 修复目标

1. 首页场景铺满主内容区域，输入框悬浮在数字人场景内部并保持紧凑尺寸。
2. 导航收起控制移动到导航与内容分割线中间，使用简约左右尖括号图标。
3. 语音优先使用后端实时 PCM/ASR；后端未配置时使用浏览器原生中文语音识别，将最终转写复用现有 SSE Agent 链路。
4. 语音识别过程可停止，异常时自动复位，不产生重复提交。
5. 保持文本改口、中断、过期事件隔离和现有数字人播报链路。

## 3. 验收标准

- 桌面端首页不再在底部切出独立面板，背景和数字人覆盖整个主场景，输入框位于场景下部并不遮挡主要人物。
- 导航收起按钮不属于导航内容区，位于分割线中部；移动端不显示该桌面控制。
- 浏览器支持 Web Speech API 时，即使后端 ASR 未配置，语音按钮可点击、可显示聆听状态、可停止，并把最终中文转写提交给 Agent。
- 后端实时 ASR 可用时优先使用后端链路，不重复启动浏览器识别。
- 浏览器不支持语音且后端未提供音频能力时，按钮保持禁用并通过 tooltip 明确原因。
- 前端 TypeScript 构建及聊天、实时、布局契约测试通过；后端现有测试不回归。

## 5. 完成记录
