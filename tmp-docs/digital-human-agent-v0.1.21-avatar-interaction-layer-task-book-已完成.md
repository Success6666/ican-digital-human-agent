# 数字人 Agent v0.1.21 连接后交互层修复任务书

## 原始问题

星云数字人连接成功后，SDK 注入的画布覆盖首页对话输入框，文本输入和语音按钮均无法点击。

## 修复方案

1. 将数字人渲染容器限制为展示层，不参与首页控件的鼠标/触摸命中。
2. 将对话栏提升到独立交互层，确保文本框、语音和发送按钮始终可点击。
3. 保持数字人画面可见，不改变星云 SDK 的初始化、播报和中断逻辑。

## 验收标准

- 未连接、连接中、连接成功三种状态下，输入框均可聚焦。
- 连接成功后语音按钮仍可点击；后端语音不可用时使用浏览器语音降级。
- 数字人画布继续正常渲染，不被输入框层级改动隐藏。
- Web 构建与交互层契约测试通过。

## 完成记录

状态：已完成。已隔离星云渲染层的指针事件，并将首页对话控件提升到交互层。
