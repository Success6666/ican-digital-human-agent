# 数字人 Agent v0.1.22 首页视口与交互动效任务书

## 原始问题

首页底部存在未使用的空白区域和残留分割线；侧边栏收起、页面切换、对话抽屉及后台配置弹窗缺少连续过渡，视觉上出现闪现和跳变。

## 修复方案

1. 首页使用独立的满高工作区，移除通用页面内边距造成的底部空白。
2. 控制台主体采用平滑的网格列宽过渡，侧边栏收起/展开保持布局连续。
3. 页面内容统一使用进入动画；对话抽屉、遮罩、配置弹窗增加淡入和位移动画。
4. 保留 `prefers-reduced-motion` 降级策略，避免影响对动效敏感的用户。

## 验收标准

- [x] 首页数字人场景从顶部栏下方铺满到视口底部，不出现无意义空白和残留分割线。
- [x] 侧边栏收起/展开存在连续过渡，不闪现、不改变内容点击区域。
- [x] 首页、RAG、评测、审计、后台配置等页面切换有统一进入过渡。
- [x] 对话抽屉和配置弹窗打开时有淡入/位移动效，交互层级不受影响。
- [x] 前端布局契约测试、聊天契约测试、实时音频测试和生产构建全部通过。
