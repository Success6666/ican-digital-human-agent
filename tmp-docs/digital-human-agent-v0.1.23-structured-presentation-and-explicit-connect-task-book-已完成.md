# 数字人 Agent v0.1.23 结构化表现与显式连接任务书

## 原始问题

1. LLM 当前主要返回纯文本，AgentResponse 虽有基础 `emotion`、`gesture` 字段，但没有稳定、可校验、可扩展的数字人表现 schema。
2. 首页首次发送消息时才隐式创建数字人会话，创建过程会清空或延迟当前消息，造成消息丢失和数字人不播报。

## 修复方案

1. 将 Agent 输出统一为文本与 `presentation` 结构，包含微表情、动作、注视、强度、持续时间、口型同步和可打断属性；兼容旧字段并在服务端做严格校验与安全回退。
2. 首页增加“连接数字人”显式按钮，连接完成后再允许实时播报；用户在连接过程中提交的文本进入队列，连接成功后只发送一次，不丢失。
3. 前端将结构化表现事件传递给数字人 Runtime，Runtime 适配器按能力映射，供应商不支持时保持文本播报链路可用。

## 验收标准

- [x] AgentResponse 返回可校验的表现 schema，字段有默认值和范围约束。
- [x] SSE `start`、`filler`、`delta`、`provider`、`done` 事件包含可消费的表现字段。
- [x] 首页存在明确的连接按钮，创建会话不依赖首次发送消息。
- [x] 连接期间输入文本和语音转写不丢失，连接成功后只触发一次响应。
- [x] 现有文本聊天、语音、打断和 Provider 兼容性测试全部通过。
