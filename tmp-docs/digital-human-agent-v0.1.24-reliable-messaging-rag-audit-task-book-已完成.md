# 数字人 Agent v0.1.24 可靠消息、RAG 与审计任务书

## 范围

1. LLM 输出增加可校验的数字人表现结构，支持微表情、动作、注视、口型同步和打断。
2. 首页显式建立/断开数字人连接；首次发送消息不得因连接过程丢失，回复必须进入数字人播报链路。
3. 接入 RabbitMQ 作为可靠消息边界，提供可追踪、可重试、幂等的播报任务模型。
4. RAG 支持本地常见文档上传并进入 Docling 解析入库流程；页签使用页内卡片切换，不重复渲染内容。
5. 审计中心按同一运行日志聚合链路，默认折叠；展开后展示完整执行流程图。

## 验收标准

- [x] LLM/AgentResponse 的表现 schema 可校验并在 SSE、同步响应中透传。
- [x] 首页存在连接/断开按钮；连接中提交的消息只消费一次，连接成功后能播报。
- [x] RabbitMQ 连接可配置，消息失败可重试并有幂等键；未配置时本地可靠队列仍可用。
- [x] RAG 支持 pdf、docx、pptx、xlsx、txt、md 等扩展名上传，显示真实处理状态。
- [x] RAG 页签为卡片切换，页面不通过锚点滚动，不出现重复内容。
- [x] 审计运行日志按 trace 聚合，默认收起，展开显示节点流程和状态。
- [x] 前后端测试和构建通过；Docker 已启动 RabbitMQ，Agent 镜像重建受外网 PyPI/Docling 下载超时影响。
