# ICAN 数字人 Agent v0.1.3 控制台视觉与页面任务书

## 任务状态

- 状态：已完成（2026-08-30）
- 创建日期：2026-08-30
- 目标版本：v0.1.3
- 关联范围：`apps/web`

## 原始问题

现有控制台已经具备首页、RAG、评测、审计、配置和实时会话能力，但视觉语言偏暗色工程面板，页面层级、导航、数据图表和数字人主视图与产品定位不一致。用户提供了三张浅色数字人控制台概念图，要求将其作为风格与布局参考，形成可长期维护的产品化前端。

## 目标

在不破坏现有认证、API、实时 WebSocket 和页面路由契约的前提下，完成一套统一的浅色控制台体验：

1. 左侧导航可收起，移动端可抽屉化；
2. 首页第一视口突出数字人运行区、会话输入和实时状态；
3. RAG、评测、审计、后台配置页面具备可扫描的指标、表格、图表、筛选和空/错/加载状态；
4. 所有底层字段转换为人类可读文案，图标统一使用 Lucide；
5. 颜色、间距、字体、状态和交互全部由共享设计令牌驱动，支持响应式和减少动画模式；
6. 维持高信息密度，正文与按钮字号克制，避免页面成为营销落地页。

## 非目标

- 不把概念图截图直接作为页面背景或产品资源；
- 不改动后端 API、实时协议、鉴权边界和供应商 SDK；
- 不引入重量级图表或状态管理依赖；
- 不在本版本虚构真实 ASR、TTS、Provider 结果。

## 实施拆分

### A. 设计上下文与令牌

- 建立 `PRODUCT.md` 与 `DESIGN.md`，记录产品型界面定位、浅色调色板、字体、间距、圆角、阴影、状态和响应式规则；
- 将颜色和尺寸集中到主题令牌，页面不散落硬编码颜色。

### B. 应用壳与首页

- 重做顶部栏、可收起侧栏、移动抽屉、用户菜单和全局状态；
- 首页提供数字人视觉占位/运行画布、Provider/会话信息、文本与实时语音入口、转写/回答/链路事件状态；
- 保留实时断线、改口、中断和能力降级的人类可读提示。

### C. 工作台页面

- RAG：知识库指标、知识库列表、检索测试、文档解析状态和空状态；
- 评测：Token/价格、成功率、工具准确率、结果正确性/一致性、事实有据性、Agent/数字人延迟、安全指标和 Trace 回放入口；
- 审计：事件筛选、风险等级、时间/操作者/资源展示和脱敏详情；
- 配置：数字人、LLM、Embedding、Docling、遥测和 Provider 状态。

### D. 质量验证

- `npm run build` 必须通过；
- 现有实时 Node 测试必须通过；
- 在桌面宽屏、平板和 375px 移动宽度检查无横向溢出、文字不遮挡、导航可操作；
- 检查键盘焦点、按钮 aria-label、禁用/加载/错误/空状态和 `prefers-reduced-motion`；
- 新增或修改的前端源文件按功能模块归档，单文件不超过 300 行。

## 验收标准

1. [x] 首屏能看到数字人主视图和会话入口，左侧导航与参考图同样承担主要工作区导航职责；
2. [x] 五个导航页面均可通过现有 hash 路由访问，且刷新、移动端抽屉和收起状态正常；
3. [x] 指标、图表、表格、筛选和 Trace 回放使用真实现有数据或明确的空/未配置状态，不展示凭证、原始内部 payload 或不可读 ID；
4. [x] 实时文本、录音能力、改口、中断、断线恢复和能力降级在新视觉下仍可操作；
5. [x] 浅色主题正文对比度满足可读性要求，主要交互目标不小于 44px，减少动画模式下无强制动画；
6. [x] 构建、测试和响应式检查记录在任务书中；
7. [x] 全部验收完成后，将本文件重命名为 `digital-human-agent-v0.1.3-console-reference-task-book-已完成.md`，再提交功能版本。

## 实际验收记录

- 页面结构：浅色高密度控制台、可收起侧栏、移动抽屉、顶部全屏/通知入口和五个 hash 页面已完成。
- 首页：数字人运行画布、Provider 状态、Fay/运行时提示、实时面板、会话输入和事件时间线已按能力状态渲染；未配置媒体时不伪造视频或语音效果。
- RAG：知识库、文档解析、检索测试、入库表单和趋势空状态已拆分为模块；数据缺失时显示“—/接入数据后更新趋势”。
- 评测：Token/价格、任务成功率、工具调用准确率、结果正确性与一致性、事实有据性、注入防护、Agent/数字人延迟和 Trace 回放均有可读视图。
- 审计与配置：风险等级、事件筛选、脱敏信息、数字人 Provider、LLM、Embedding、Docling 和遥测状态均使用人类可读文案。
- 认证体验：浏览器请求统一携带同源会话 Cookie，前端不再持久化登录令牌；旧版本地令牌会在升级后清理。
- 响应式：Edge 390×844 与 1440×1000 检查通过；五个桌面页面和移动首页 `scrollWidth` 均未超过视口，移动抽屉可打开。
- 自动化：`npm run build`、`npm run test:realtime` 通过；无 `signal-grid` 残留；生产前端源文件均不超过 300 行；无页面运行时错误。

## 风险与后续

- 当前数字人媒体仍由 Provider/SDK 能力决定，首页在未配置真实媒体时展示明确的运行时占位，不伪造播报；
- 后续接入真实视频流时，沿用现有 Runtime 边界，不把供应商字段泄露到 UI；
- 图表数据未来可切换到持久化评测与遥测服务，组件只依赖人类可读的视图模型。
