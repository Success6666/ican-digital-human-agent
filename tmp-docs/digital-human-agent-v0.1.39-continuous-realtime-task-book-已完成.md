# Digital Human Agent v0.1.39 持续实时对话模式任务书

## 状态

已完成（2026-09-02）

## 原始问题

当前 PCM 实时链路仍按单次录音操作：用户每轮需要重新点击麦克风。数字人回答结束后不会自动恢复聆听，交互更像语音输入框，而不是持续实时对话。

## 目标

1. 点击一次进入持续实时对话，自动完成“聆听、静音收口、理解、回答、继续聆听”的循环。
2. 再次点击才退出实时模式；退出后停止当前采集并清理自动恢复任务。
3. Agent 思考和数字人表达期间不抢占式重开 PCM，避免新 `audio_start` 误中断正在生成的回答。
4. 浏览器语音识别回退在回答期间暂停，回答完成后自动恢复，减少扬声器回声被识别成用户输入。
5. 保留 VAD、音量波纹、低延迟收口以及文本输入能力。

## 验收标准

1. PCM 路径进入实时模式后立即开始聆听；VAD 结束一轮后等待 `run_done/done`，在 idle 状态自动开始下一轮。
2. 思考、表达、错误、断线和页面会话切换期间不会重复创建录音器；自动恢复使用单个可取消计时器。
3. 浏览器识别回退在 `isSending` 期间停止采集，不自动重启；响应结束后继续同一实时模式。
4. 按钮使用实时模式语义和持续激活状态，不再把每一轮显示为一次录音任务。
5. Web、Agent、Auth 测试及 Compose 健康检查通过；生成验证与回滚材料并提交 v0.1.39。

## 回滚方案

恢复 v0.1.38 的单轮录音按钮逻辑；回滚脚本只验证副本，不覆盖工作树源码。
