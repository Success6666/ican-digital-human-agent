# ICAN 数字人 Agent v0.1.4 首页参考图重构任务书

## 1. 任务信息

- 项目：ican 通用数字人 Agent 底座
- 版本：v0.1.4
- 创建日期：2026-08-30
- 状态：已完成

## 2. 原始问题

当前首页把 Provider 选择、运行链路、实时事件时间线、数字人占位图和 Agent 对话同时堆叠在主工作区，与目标参考图的单一沉浸式交互布局不一致，且把 FutureAGI 负责展示的实时观测信息重复暴露给终端用户。

## 3. 重构目标

1. 首页只保留左侧导航、中央数字人展示区和底部一个对话输入框。
2. Provider 切换、连接配置等操作只在后台配置页面提供，首页不出现供应商选择控件。
3. 首页不显示实时事件流、Runtime 链路、底层调试状态；Trace 回放只保留在审计中心。
4. 数字人未建立真实连接时不渲染任何人物，只显示“等待数字人连接”。
5. Agent 对话记录默认收起，在右侧提供图标按钮，点击后展开抽屉；关闭后不占用首页主要视觉区域。
6. 保留实时语音/文本交互能力，输入框和连接状态使用人类可读文案。
7. 桌面端贴合参考图的浅蓝背景和大留白，移动端保持输入框、抽屉和导航可用。

## 4. 实施边界

- 不修改 Agent、MCP、RAG、FutureAGI 和 Provider 后端协议。
- 不在首页伪造数字人媒体内容；真实媒体由 Provider SDK 接入后再渲染。
- 审计中心继续提供 Trace 列表与回放，不迁移或删除现有审计能力。
- 通过模块化组件和页面级样式实现，避免继续扩大单文件耦合。
