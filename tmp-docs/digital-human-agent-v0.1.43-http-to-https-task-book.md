# 数字人 Agent v0.1.43 HTTP 到 HTTPS 端口跳转修复任务书

状态：已完成  
版本：v0.1.43  
日期：2026-09-02

## 原始问题

用户通过 `http://39.97.253.99:16666` 访问时，Nginx 返回 `400 Bad Request: The plain HTTP request was sent to HTTPS port`，造成公网入口不可用的误判。

## 修复方案

在 16666 的 TLS server 中增加 Nginx 497 错误跳转，将误用明文 HTTP 的请求重定向到同端口 HTTPS；保留 6666 原有监听，并同步云端配置、文档和版本号。
