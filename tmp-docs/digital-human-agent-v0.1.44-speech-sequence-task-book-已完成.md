# 数字人 Agent v0.1.44 流式语音顺序播报修复任务书

状态：已完成  
版本：v0.1.44  
日期：2026-09-02

## 原始问题

流式响应快速产生多个句段时，数字人可能跳过前面的句段，直接播报后面的内容，导致回复不完整。

## 修复方案

1. 取消对单个已分句文本的无故滞留，句段一出现即可进入播报队列。
2. 每个句段都绑定 `client_speak_id` 并等待对应的 `speak_end`，前一段结束后才发送下一段。
3. 播报超时立即终止当前队列并提示错误，避免静默丢段。
4. 最后一段结束后清理本地流状态，下一轮从新的 SDK 播报边界开始。

## 验收标准

- [x] 快速连续分片不会在 SDK 中产生重叠 `speak_start`。
- [x] 标点句段出现后立即进入队列，不等待后续分片。
- [x] 每个句段等待对应 `speak_end` 后才发送下一段。
- [x] 播报超时不会继续发送后续段，且会进入错误状态。
- [x] 前端语音测试和生产构建通过。
