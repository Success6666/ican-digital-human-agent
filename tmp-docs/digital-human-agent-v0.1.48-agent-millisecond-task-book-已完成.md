# 数字人 Agent v0.1.48 Agent 毫秒级链路优化任务书

状态：已完成  
版本：v0.1.48  
日期：2026-09-02

## 原始问题

当前 Agent 链路包含请求校验、会话状态、偏好加载、响应缓存、图编排、RAG、SSE 帧封装和数字人展示等多个阶段。RAG 已完成本地热路径优化，但 Agent 端尚未建立分段耗时基准，缓存命中和流式首帧仍有额外调度、序列化或阻塞 I/O。

## 优化目标

1. 将本地可控热路径压缩到毫秒级，重点优化缓存命中、会话状态、首帧输出和事件封装。
2. 保持 LLM、远端数字人和 ASR 的真实推理/网络耗时，不把端到端耗时伪装成毫秒级。
3. 建立首帧、缓存命中、RAG、图启动和 SSE 输出的 p50/p95 基准，并保存每轮原始数据。
4. 保持租户隔离、响应顺序、取消语义、历史记录和流式播报完整性。

## 验收标准

- [x] Agent 本地缓存命中 p50/p95 达到毫秒级。
- [x] 流式 `start`/首个 `delta` 不等待无关的记录写入或远端展示调用。
- [x] 偏好、缓存和会话读取不在一次请求中重复执行。
- [x] 图运行与 SSE 帧顺序、取消和错误语义回归测试通过。
- [x] 分段性能原始 JSON 持久化，标明缓存命中与真实推理。
- [x] Compose 部署健康，版本元数据和验收材料完成提交。
