# 数字人 Agent v0.1.53 官方动作与表情能力任务书

日期：2026-09-08
状态：已完成

## 原始问题

TTSA 播报请求曾因字段或取值不符合星云数字人接口而返回错误。现有止血改动仅默认关闭情绪字段，尚未完成官方协议核验，也未把官方支持的动作与表情能力完整、可验证地提供给 Agent 选择。

## 目标

1. 以魔珐星云官方文档、官方示例和当前实际加载的官方 SDK 为唯一协议依据。
2. 核对 TTSA `speak` 调用、SSML 事件、动作语义与情绪配置的准确结构、类型和能力边界。
3. 建立经过官方核验的动作与表情能力目录，并保证 Agent 提示词、服务端校验和前端适配集合一致。
4. 对未知、角色不支持或文档未定义的值采取确定性降级，保证文本播报不中断。

## 实施方案

1. 记录官方来源及其版本或访问日期，逐项整理字段和枚举证据。
2. 将动作、表情目录放入 Agent 服务的稳定模型层，并用全量测试约束前端适配集合。
3. 收紧 LLM 输出约束与解析校验，使 Agent 只能从官方能力目录选择。
4. 前端仅把已验证的动作/表情转换为官方请求格式；能力需角色配置时，通过显式配置启用。
5. 增加覆盖全部官方枚举、别名、未知值、XML 转义、情绪开关和连续播报的自动化测试。

## 验收标准

- 官方请求字段、嵌套位置、类型和枚举均能追溯到官方文档或当前官方 SDK，不存在推测字段。
- 官方公开支持的动作与表情全部进入统一目录，并可供 Agent 选择。
- Agent 生成、服务端模型和前端转换使用一致的能力集合；未知值不会透传给 TTSA。
- 角色级能力限制有明确配置和降级路径，默认配置可稳定播报。
- Web 动作专项测试与生产构建通过；相关 Agent 测试通过。
- 版本、API 文档和变更说明保持一致。
- Git 差异检查通过，提交仅包含本功能包和同一未完成续作的已有改动。

## 完成条件

全部验收标准通过后，将状态改为“已完成”，并把文件名追加 `-已完成`。
