# 数字人背景比例修复任务书

## 原始问题

星云 SDK 注入的背景素材为 `1080×1920`，但其图片节点带有 `width:100%;height:100%` 内联样式，导致在横向数字人舞台中发生非等比横向拉伸。静态预览层与实时 SDK 层的背景裁切规则也不一致。

## 修复方案

1. 在首页数字人运行时容器中统一覆盖 SDK 背景图片的展示规则。
2. 使用 `object-fit: cover` 与居中定位，保持素材宽高比并统一基础背景、桌面前景的裁切方式。
3. 保持静态预览与实时运行时的现有生命周期策略，不改变对话、会话和数字人连接逻辑。

## 验收标准

- [x] 星云基础背景与桌面前景图片均不再发生非等比拉伸。
- [x] 数字人头部、身体和桌面前景在 1440×900 浏览器视口中完整可见且水平居中。
- [x] 首页创建会话后可正常连接星云并完成一次文本对话。
- [x] `/api/chat/stream` 返回 200，包含数字人表现事件与完成事件。
- [x] 前端 TypeScript 构建通过，实时链路回归测试通过。
