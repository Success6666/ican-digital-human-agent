# Digital Human Agent v0.1.6 真实数据与数字人 Runtime 修复任务书

**状态：已完成**  
**创建日期：2026-08-30**

## 原始问题

1. RAG 页面将内存向量库的切片数量显示为文档数量，并展示两个没有后端数据来源的固定知识库条目。
2. 首页创建会话后只建立 Agent 实时通道，数字人区域仍是空 DOM 容器，没有加载或初始化供应商 Web SDK。
3. 魔珐星云 Provider 仅完成配置状态识别，创建会话不返回浏览器 Runtime 参数，Agent 输出也没有驱动浏览器数字人播报。

## 修复目标

1. RAG 页面只显示当前登录用户真实存在的知识库集合、去重文档数和切片数。
2. 为魔珐星云增加可替换的浏览器 Runtime，实现 SDK 加载、WebGL 容器挂载、初始化进度、错误展示和销毁。
3. 将已完成的 Agent 回复交给魔珐 Runtime 播报，并在中断、切换会话和离开页面时停止或销毁实例。
4. 保持供应商逻辑隔离，后续阿里云、讯飞和 Fay 可通过相同前端 Runtime 接口接入。

## 实施步骤

1. 扩展 RAG Store 统计契约与健康接口，按用户聚合真实集合、文档和切片数据。
2. 调整 RAG 前端类型和列表，删除固定知识库数据及无实际功能的开关。
3. 扩展魔珐会话参数与白名单，按官方文档提供 SDK 初始化所需字段。
4. 新建数字人浏览器 Runtime 接口、魔珐 SDK 加载器和 React 挂载组件。
5. 将最终 Agent 回复与中断信号连接到数字人 Runtime，补充安全策略和响应式样式。
6. 增加后端、前端测试，执行生产构建、Docker 部署和浏览器视觉验证。

## 验收标准

1. 空知识库时页面只显示真实的空状态；入库后集合名称、文档数、切片数与服务端存储一致。
2. RAG 健康接口不混淆文档数和切片数，不返回其他用户的数据。
3. 默认 Provider 切换为魔珐后，点击建立会话可看到 SDK 加载进度并出现真实数字人 Canvas。
4. SDK 初始化失败时页面显示人类可读错误，不显示虚构人物或空白连接成功状态。
5. Agent 最终回复可触发数字人播报；新指令、中断或会话销毁可停止上一轮表达。
6. 长期凭据不写入仓库、日志或配置查询接口；浏览器侧参数仅通过已认证会话按供应商白名单返回。
7. Agent、认证网关和 Web 相关测试及生产构建通过，Docker 服务保持健康。
