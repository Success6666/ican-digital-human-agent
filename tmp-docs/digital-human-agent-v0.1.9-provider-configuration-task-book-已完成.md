# 数字人 Agent v0.1.9 Provider 配置任务书

## 目标

将后台配置从仅支持魔珐星云扩展为阿里云、魔珐星云、讯飞三家数字人 Provider 的统一配置入口。配置必须真实保存、重启后恢复、服务端掩码返回，并影响 Provider 健康状态与默认运行时选择。

## 范围

- Agent 服务：增加 Aliyun、iFlytek 配置模型、环境应用、接口 DTO 和持久化逻辑。
- Web 控制台：增加两家 Provider 的弹窗配置，沿用现有视觉规范，不展开底层配置项。
- 权限：仅管理员可读取和修改配置。
- 验证：配置单测、前端构建、Docker 健康检查。

## 验收标准

- [x] 三家 Provider 均可在后台打开独立配置弹窗。
- [x] 启用前校验必填凭证，保存失败不覆盖旧配置。
- [x] 配置写入服务端持久化文件，重启后仍生效。
- [x] API 不返回完整密钥，页面只展示掩码或已配置状态。
- [x] 默认 Provider 只能选择当前健康且已配置的 Provider。
- [x] 普通用户无法读取或修改配置。
- [x] Agent 全量测试、Web 构建和 Docker 健康检查通过。

已完成（2026-08-31）。
